# G6 — Human Cognition and Memory

## Goal

Give human agents bounded internal state without global knowledge.

## Causal boundary

Cognition may read only what the human can perceive locally plus that individual's retained memory. It may influence that individual's later action choice. It may not inspect global world state, other agents' hidden state, observer labels, or future state.

## Mechanisms

- local perception;
- bounded episodic memory;
- remembered locations;
- individual recognition slot;
- learned expectations from reward/error;
- uncertainty;
- bounded forgetting;
- one-step planning horizon.

## Explicitly deferred

- language;
- teaching;
- imitation;
- named tools or technologies;
- institutions;
- culture;
- global maps;
- omniscient pathfinding.

## Exit condition

Two agents exposed to different histories must be able to make different later choices when presented with identical immediate surroundings.

Checkpoint/replay must preserve cognition exactly.
