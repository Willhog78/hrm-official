# Homo agentus terminology

## Canonical name

The embodied sapient species in HRM Genesis is **Homo agentus**.

Use **Agentus** as the ordinary short form in documentation, experiment reports, observer output, and project discussion.

## Legacy implementation identifiers

Existing module, authority, state, configuration, and test identifiers that use `human` remain temporarily for compatibility, including paths such as `hrm_genesis/human/` and fields such as `human_biology_enabled`.

Those identifiers are implementation archaeology, not the canonical species name. They should not be interpreted as a claim that the simulated species is Homo sapiens.

Avoid broad renames unless they can be performed as an isolated compatibility-safe migration.

## Modeling rule

Agentus receives no privileged civilizational knowledge or scripted destiny. It is an embodied organism in the same causal world as other life, subject to ecology, weather, fire, predation, injury, reproduction, death, learning, and material constraints.
