# G9 — Observer

## Goal

Describe what emerges without controlling it.

## Hard boundary

The Observer is not a simulation authority, owns no causal resource, registers no schedule, submits no mutation, and appears in no transaction.

It receives copied snapshots and returns descriptive measurements and classifications only.

## May classify

- persistent groups;
- specialization;
- exchange;
- conflict;
- hierarchy;
- behavioral transmission;
- technology-like action patterns;
- ecological and population effects.

A classification is a description, not a causal fact. It never writes back into human memory, decisions, population identity, ecology, matter, or world state.

## Exit condition

Running with observation calls and running without them must produce identical causal simulation state and ledger results.
