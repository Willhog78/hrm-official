# G4 Autonomous Ecology Qualification Contract

## Milestone

G4 qualifies **Autonomous Computational Ecology v1**.

The production run must continue for at least 100 simulated years without an operator injecting organisms, food, water, population targets, recovery events, or replacement populations.

## Zero-intervention run

The century run may use only the causal mechanisms already present in the simulation:

- climate forcing generated by World;
- hydrology and material transfer owned by Matter;
- producer growth, reproduction, death and decomposition;
- consumer perception, movement, feeding, drinking, reproduction, aging and death;
- deterministic Stage-1 scheduling, replay and checkpointing.

No qualification helper may mutate the live century run.

## Required evidence

The run must demonstrate:

1. completion of at least 100 simulated years;
2. valid replay/provenance chain;
3. elemental conservation across Matter + producers + consumers;
4. water accounting across environmental reservoirs + consumer bodies/carcasses + declared open-system input/output;
5. ecological state that actually changes over the run;
6. no Human authority or Human semantics.

The milestone does **not** require every species to survive forever. Extinction is a valid outcome if it follows from lower-level causes.

## Controlled perturbation experiments

Drought/local-collapse/recovery tests are separate experiments.

They may alter declared boundary conditions to ask causal questions such as:

- does regional water loss reduce biomass?;
- can an unstressed region persist while another collapses?;
- can producer occupancy recover when viable conditions return?;
- do consumers migrate as local food/water conditions change?

Perturbations must conserve or explicitly account for any matter they remove. They are never allowed to become automatic rescue logic in the production simulator.

## Failure rule

G4 fails if the world survives only because test code or runner code detects a bad state and repairs it.
